验证与调试

不要一上来就训练：先验证资产和机器人稳定，再验证环境 reset/step，最后才做 teleop/训练。

目录 总览 assets 清单 robot cfg env_cfg teleop pipeline actuator / regex 扫盲 坐标系/关节轴 任务注册 验证与调试 R11 对照

推荐验证顺序

  1. USD 单独打开：mesh/材质/关节层级/碰撞体/质量惯量。
  2. 只 spawn 机器人：确认不爆炸、不穿地、站姿合理。
  3. 检查关节名匹配：regex 是否覆盖了预期 DOF。
  4. 调 actuator：从保守参数到目标参数，观察抖动/软/爆。
  5. 跑 env：先 reset + zero action，再 random action。
  6. 最后接 teleop 或训练。

常用脚本

./isaaclab.sh -p scripts/environments/list_envs.py
./isaaclab.sh -p scripts/environments/zero_agent.py --task Isaac-PickPlace-R11-Abs-v0 --num_envs 1
./isaaclab.sh -p scripts/environments/random_agent.py --task Isaac-PickPlace-R11-Abs-v0 --num_envs 1

常见问题速查

现象 优先检查
机器人不可见/mesh 丢 USD 依赖路径、meshes/ 是否齐全。
一按 play 就爆炸 碰撞体重叠、自碰撞、惯量异常、初始姿态穿地、solver iteration。
关节不动 joint_names_expr 是否匹配、USD drive 是否存在、关节是否 mimic/fixed。
动作很软/跟踪差 stiffness/damping、armature、effort_limit_sim 是否合理。
