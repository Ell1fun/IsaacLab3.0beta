任务注册

把一个 env_cfg 绑定到一个 Gymnasium 环境 ID，脚本才能用 --task 创建环境。

目录 总览 assets 清单 robot cfg env_cfg teleop pipeline actuator / regex 扫盲 坐标系/关节轴 任务注册 验证与调试 R11 对照

最常见注册方式

gym.register(
  id="Isaac-MyTask-MyRobot-v0",
  entry_point="isaaclab.envs:ManagerBasedRLEnv",
  kwargs={
    "env_cfg_entry_point": "your.module.path:YourEnvCfgClass",
  },
  disable_env_checker=True,
)

字段解释

  • id：你在脚本里传的任务名。
  • entry_point：要实例化的环境类（manager-based 通常是 ManagerBasedRLEnv）。
  • env_cfg_entry_point：指向 env_cfg 类，格式 python.module:ClassName。
  • disable_env_checker：Isaac Lab 任务里常设为 True。
最常见错误是：模块路径写错、类名写错、或者注册模块没有被导入执行，导致“任务 ID 找不到”。
