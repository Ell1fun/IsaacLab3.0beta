完整 skill 的职责拆分

材料负责什么不负责什么
Schema定义 spec 字段结构、类型、枚举、必填/可选和条件必填。不告诉 AI 怎么写代码。
Presets把仓库中已经确定的机器人/物体事实固化下来，用于 schema gate 前自动补齐 spec。不负责发明仓库里没有的新机器人或新资产。
Spec Builder Prompt把用户自然语言整理成 spec，并根据校验错误做 gap analysis。不生成 env_cfg。
Template Generator根据已通过 schema gate 的 spec 和仓库已有模板，确定性生成 env_cfg、注册任务和启动命令。不让模型自由编写仓库内已有任务模板。
Generator Prompt仅作为 fallback/参考：当后续支持非模板场景时，约束模型如何生成代码。当前优先级低于模板生成器。
Checklist生成后验收路径、import、joint/link、action layout、teleop pipeline、注册。不代替真实运行测试。
Examples提供 R11/G1 这类已知任务的输入样例和期望输出摘要。不保证新机器人可以直接复用。

进一步阅读：Presets 与 Prompts 的可维护边界

如果你想让知识库更“可维护”，最关键的是把 presets/ 与 prompts/ 当成两类独立资产来管理。 具体字段清单、哪些字段被 workflow 消费、每个 prompt 在什么时候会触发，都整理在： Presets & Prompts。
