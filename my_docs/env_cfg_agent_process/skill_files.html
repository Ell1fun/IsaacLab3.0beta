完整 skill 的职责拆分

材料负责什么不负责什么
Schema定义 spec 字段结构、类型、枚举、必填/可选和条件必填。不告诉 AI 怎么写代码。
Spec Builder Prompt把用户自然语言整理成 spec，并根据校验错误做 gap analysis。不生成 env_cfg。
Generator Prompt根据已通过 schema gate 的 spec 生成 env_cfg、注册任务和启动命令。不跳过 schema gate。
Checklist生成后验收路径、import、joint/link、action layout、teleop pipeline、注册。不代替真实运行测试。
Examples提供 R11/G1 这类已知任务的输入样例和期望输出摘要。不保证新机器人可以直接复用。
