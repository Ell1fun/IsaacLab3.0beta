AI Agent 生成 env_cfg：落地路线

从当前最小雏形到成熟产品化 skill 的推进计划。

目录 总览 架构分层 Schema / Spec Workflow Orchestrator Skill 文件 落地路线

当前状态

  • 已经有 PickPlaceVRSpec schema。
  • 已经有 Spec Builder prompt 和 Generator prompt。
  • 已经有 post-generation checklist。
  • 已经有 R11 / G1 Inspire Hand 示例 spec。
  • 已经有 orchestrator：route / template / validate / generate / chat。
  • 已经明确第一阶段支持 IsaacLab 仓库内封装好的人形机器人预设。

下一步优先级

  1. 用 R11/G1 现有 env_cfg 继续校准 examples 里的 joint/link/hand joint 顺序。
  2. 把 Spec Builder 的追问从“输出 questions”升级为真正的多轮问答状态管理。
  3. 把 Generator 输出接入 post-generation checklist 的自动检查。
  4. 实现 task 注册文件的安全 patch，而不是整文件覆盖。
  5. 加入一次真实 dry-run：读取 example spec → 生成 env_cfg payload → checklist 报告。

产品化路线

阶段目标交付物
V0本地理解和验证流程。schema + 文档 + CLI orchestrator。
V1接入 AI API，能对话补齐 spec。spec_builder_loop + schema gate。
V2能从 spec 生成 env_cfg 并注册任务。generator + post validation。
V3接入 Chat UI / IDE 插件 / 服务端。常驻 orchestrator + 多用户会话状态。
V4支持用户自带 USD 的机器人接入。新的 asset-to-robot-cfg skill。

当前不做的事

  • 不从零生成机器人 URDF / robot cfg。
  • 不自动猜 joint/link/EEF。
  • 不把 API Key 写进 repo。
  • 不跳过 schema gate 直接生成代码。
